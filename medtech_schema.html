raw_clearance_records

Sortie brute des 4 parsers (510k/pma/denovo/recall). Dedup automatique via upsert sur la contrainte unique.
colonnetypecontraintesnote
idINTEGERPK AUTOINCREMENT
sourceTEXTNOT NULL, UK (composite)openFDA_510k / _pma / _denovo / _recall
record_numberTEXTNOT NULL, UK (composite)k_number / pma_number / denovo_number / recall_number
device_nameTEXT
applicant_rawTEXTindex: idx_raw_applicant
decision_dateTEXTindex: idx_raw_decision_dateISO yyyy-mm-dd
decision_codeTEXT
clearance_typeTEXT
product_codeTEXTindex: idx_raw_product_code
advisory_committeeTEXT
extra_jsonTEXTchamps non-mappes, specifiques a l'endpoint
ingested_atTEXTNOT NULL, DEFAULT datetime('now')
UNIQUE (source, record_number) — la cle d'upsert, une par record par endpoint.
